What you will learn

No experience needed. Each week builds on the last, and you finish every week with a piece you can add to your personal portfolio.

  1. Week 1

    HTML: structuring web pages

    Tags, elements and attributes. Headings, lists, images, links, tables and forms. Set up VS Code, Git and GitHub.

  2. Week 2

    CSS: styling web pages

    Selectors, properties and values. Style text, colours, fonts and backgrounds.

  3. Week 3

    Box model and Flexbox

    Margin, padding and border. Positioning, and page layouts with Flexbox.

  4. Week 4

    Grid and responsive design

    CSS Grid for advanced layouts, and media queries so your sites work on phones.

  5. Week 5

    Introduction to JavaScript

    Syntax, variables, conditions, functions and event listeners.

  6. Week 6

    JavaScript for interactivity

    Change pages with the DOM. Add simple animations and user interactions.

  7. Week 7

    Bootstrap, Tailwind and AI tools

    Build faster with frameworks. Use AI tools to write, debug and improve code. Plan your portfolio.

  8. Week 8

    Final project and launch

    Finish your portfolio website, deploy it with GitHub Pages or Netlify, and present it live to the class.

By the end, you will have a real website online

You will not just watch lessons. You build, break, fix and publish, with an instructor beside you at every class.

  • A personal portfolio website, live on the internet
  • Responsive pages that work on phones, tablets and laptops
  • Git and GitHub skills to manage and share your projects
  • Confidence using AI tools while understanding the code underneath
  • A project you present live to your class
